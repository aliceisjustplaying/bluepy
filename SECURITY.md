# Security Policy

Only the latest production release of Bluepy receives security updates.

## Reporting a Vulnerability

Do not discuss security issues in public GitHub issues.

Use GitHub Private Reporting when available, or contact the maintainers directly.

Include:

- Steps to reproduce the issue
- Which parts of Bluepy are affected
- Expected impact

## Security Practices

- Use HTTPS for Bluepy and ATProto service endpoints.
- Treat OAuth tokens like passwords.
- Dependencies are monitored with GitHub security alerts.
